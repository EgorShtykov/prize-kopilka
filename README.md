# Призовая копилка

Интерактивный каталог из 30 призов для учеников 8–9 классов на индивидуальных занятиях.

## Система наград

- 250 ₽ за каждую выполненную домашнюю работу;
- обычно две домашки в неделю — 500 ₽;
- восемь домашек за четырёхнедельный цикл — до 2000 ₽;
- единый бонус 1000 ₽ за все домашки и отсутствие неотработанных пропусков;
- пропущенное занятие можно перенести или отработать и сохранить бонус;
- максимум за цикл — 3000 ₽.

Ошибки не уменьшают награду: засчитывается выполнение и доработка, а не безошибочность.

## Возможности

- каталог с фильтрами по категории, стоимости и доступной сумме;
- автоматический расчёт основной суммы и бонуса;
- выбор подарка целью и расчёт остатка;
- четыре коллекционные карточки за 2, 4, 6 и 8 домашек;
- три учебные миссии и бесплатный сюрприз после шестой домашки;
- прозрачные правила без платных случайных розыгрышей;
- адаптивная версия для компьютера и телефона.

Черновик цикла, выбранная миссия и цель сохраняются в `localStorage` только в текущем браузере. Синхронизации между устройствами и серверных аккаунтов нет; очистка данных браузера удаляет сохранённый прогресс.

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Готовая сборка появится в каталоге `dist`.

## GitHub Pages

Проект использует относительный `base: './'`. Рабочий процесс `.github/workflows/deploy.yml` собирает сайт и публикует `dist` через GitHub Actions после отправки изменений в `main`.
