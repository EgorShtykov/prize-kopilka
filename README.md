# Призовая копилка

Интерактивный каталог из 24 призов за домашние задания для индивидуальных занятий. Бюджет — до 2000 ₽ в месяц: четыре еженедельные награды по 250 ₽ и месячный бонус 1000 ₽.

## Возможности

- каталог с фильтрами по категории и стоимости;
- интерактивная копилка и расчёт доступных призов;
- выбор подарка целью и расчёт остатка;
- адаптивная версия для компьютера и телефона.

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Готовая сборка появится в каталоге `dist`.
